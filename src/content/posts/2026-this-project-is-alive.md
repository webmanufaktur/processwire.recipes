## The Big Update

We have been working hard to bring [processwire.recipes](/) into 2026, and today we're excited to share what's new.

## Astro 5.18 + Tailwind CSS v4

The entire project has been updated to the latest versions:

- **Astro 5.18** - Faster builds, better performance, and improved developer experience
- **Tailwind CSS v4** - A complete rewrite with a new CSS-first configuration approach

This update ensures better performance, smaller bundles, and a more maintainable codebase.

## New: ProcessWire AI Skills

We are thrilled to announce a brand new **ProcessWire Skills** section. This is a collection of AI prompts and workflows specifically designed for ProcessWire developers.

### What's Inside

The skills cover essential ProcessWire topics:

- API usage
- Hooks and events
- Fields and templates
- Modules development
- Security best practices
- Selectors
- Multi-language sites
- And much more

### Repositories

The project consists of two repositories:

- **[pwaiworkflow](https://github.com/webmanufaktur/pwaiworkflow)** - The main skill definitions and AI prompts
- **[pwaiworkflow-profile](https://github.com/webmanufaktur/pwaiworkflow-profile)** - A ready-to-use ProcessWire profile that serves as a playground for learning

You can clone the profile, set it up locally, and start practicing ProcessWire development with AI assistance right away.
